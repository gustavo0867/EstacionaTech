# Sistema de Controle de Estacionamento

Este projeto foi desenvolvido em grupo na disciplina de **Desenvolvimento de Projetos II** e visa criar um sistema de controle de estacionamento utilizando Python com arquitetura MVC. O sistema é para ambiente desktop e tem como objetivo automatizar a gestão de vagas, entradas e saídas de veículos, além de gerar relatórios financeiros e facilitar o controle de tarifas.

## Funcionalidades

- **Cadastro de Veículos**: Registro de informações como placa, modelo e cor.
- **Gerenciamento de Vagas**: Controle em tempo real das vagas disponíveis e ocupadas.
- **Registro de Entradas e Saídas**: Anotação dos horários de entrada e saída de veículos.
- **Cálculo de Tarifas**: Definição de diferentes tarifas (horárias, diárias, mensalistas).
- **Emissão de Relatórios**: Geração de relatórios financeiros detalhados.
- **Administração de Sistema**: Definição de preços, zonas e controle de vagas.

## Tecnologias Utilizadas

- **Python**: Linguagem de programação para o desenvolvimento do back-end.
- **Flask**: Micro-framework utilizado para construir a aplicação web.
- **HTML, CSS e Jinja2**: Tecnologias de front-end para a criação da interface do usuário e o uso de templates.
- **Arquitetura MVC (Model-View-Controller)**: Padrão de design que organiza o código, separando a lógica de negócios da interface.
- **Docker**: Ferramenta de conteinerização para simplificar a implantação e o gerenciamento da aplicação.
- **ReportLab**: Biblioteca Python usada para a criação programática de relatórios em PDF.
